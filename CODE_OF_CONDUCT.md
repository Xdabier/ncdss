# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient with other people.
- Criticize ideas and code, not people.
- No harassment, insults or discriminatory language.
- Accept that maintainers may edit or remove contributions and comments that break these rules.

This applies to issues, pull requests, reviews and any other project space.

## Reporting

If someone behaves in a way that breaks this code, contact the maintainer privately through their [GitHub profile](https://github.com/Xdabier). Reports are kept confidential.
